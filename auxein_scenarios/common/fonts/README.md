# Fonts

Static instances of [Inter](https://github.com/rsms/inter) (Light, Regular, Bold) and
[Inter Tight](https://github.com/rsms/inter-tight) (Light, Regular), as served by Google Fonts, used by
`auxein_scenarios.common.theme` so that every video and chart looks the same on every machine, CI included.

Both are licensed under the SIL Open Font License 1.1 (`OFL-Inter.txt`, `OFL-InterTight.txt`), which allows bundling them
with software.
